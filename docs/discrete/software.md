# R and RStudio
Para este curso necesitamos que instales R y Rstudio

### Install R

1. Ir al sitio de [CRAN](https://cran.rstudio.com/)
2. Selecciona tu sistema operativo (Windows or Mac)
3. Sigue las instrucciones

### Instala RStudio

1. Ir al sitio de Posit [Posit](https://posit.co/download/rstudio-desktop/)
2. Click en el botón "Download for Desktop"
3. Sigue las instrucciones

Si ya tienen estos dos cosas en su computador por favor actualicen.

# RevBayes


RevBayes es la herramienta más moderna para filogenética estadística.

1. Crea una nueva carpeta en tu computadora donde sepas exactamente el path (por ejemplo en C:\Documentos\)
2. Si no sabes qué es el path te recomiendo que veas este [video](https://www.youtube.com/watch?v=8N8yiFnXa9Y) 
3. Ve al sitio de RevBayes [RevBayes](https://revbayes.github.io/download)
4. Bajen de acuerdo a su sistema en el folder que seleccionaron (Documentos) e instalen. 
5. Deben tener un folder que se llame \revbayes con la version y adentro otro folder llamado \bin

# Tracer

Tracer es una herramienta para visualización de resultados del MCMC en aplicaciones filogenéticas

1. Ve al sitio de [Tracer](https://github.com/beast-dev/tracer/releases/tag/v1.7.2)
2. Baja el archivo zip o tgz para Windows (dependiendo de la descompresión que tengas) o dmg para Mac.

# Editor de texto

Asegúrate de que tienes un editor de texto para software (Notepad para Windows funciona). A mí en lo particular me gusta [Sublime](https://www.sublimetext.com/download) y sirve para Windows y Mac.
